## Overview  
This repository houses the frontend for the Professional Cleaning South Africa website: `https://professionalcleaning.co.za/`. The website delivers professional cleaning services across South Africa and is structured to provide service descriptions, contact information, client testimonials, and a project gallery.

## Features  
- Home page with hero section, overview of cleaning services and service categories.  
- Service pages ( domestic cleaning, commercial cleaning, deep cleaning etc).  
- Contact form enabling clients to reach out for quotes.  
- Gallery/portfolio of past cleaning projects.  
- Testimonials section for client feedback.  
- Mobile-responsive layout and SEO-friendly markup.  
-  Backend/API for handling contact-form submissions and service requests.

- HTML5 / CSS3 / JavaScript 
-  React
